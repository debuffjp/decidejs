A gut feeling for your app

decidekit picks one of your labels for a piece of text in milliseconds, on the user's device, with a confidence you can trust. When it isn't sure, it can ask an LLM and learn from the answer, so it asks less every day.

import { createDecider } from "decidekit";

const d = await createDecider();
const { choice, confidence } = await d.decide(
  "my card still hasn't arrived",
  ["card_arrival", "lost_card", "refund"],
);
// choice: "card_arrival", typed as your labels

A System One model, in plain words

Kahneman called fast, intuitive thinking System 1. A System One model works the same way: it doesn't write anything, it reads the text once and picks one of the options you give it. That makes it fast, cheap and safe to wire into code, because the answer is always one of your labels. decidekit is a small one: a 34 MB sentence model that runs where your text already is.

Watch it learn from an LLM

It starts out knowing only twelve label names. What it's sure of, it answers itself. What it isn't, it asks an LLM about, and every eight answers it retrains. Type your own message to try it.

What people use it for

Cut the LLM bill

Answer the easy majority on device and send only unsure messages to an LLM, which teaches it as it goes.

Route support messages

Billing, bug, account: route a message before it's sent, and show the right help while the user types.

Command palettes

"Make it darker" to theme.dark, in milliseconds, offline.

Games

Read typed player chat and commands with no server.

Sensitive text

Health, finance and internal tools: training and deciding both stay on the device.

Agent harnesses

A free decision model for switch, with an LLM as its teacher.
